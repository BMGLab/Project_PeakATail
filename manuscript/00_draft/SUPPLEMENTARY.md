## Fig S1 | The datasets behind every headline number, with the poly(A) clip rate

**(a)** Per-library table for the four benchmark arms and the cohort: chemistry, upstream pipeline, read-2 length, cells, and the identical v2 parameter block (108 recorded parameters; the only library parameter is `--seq-len`, the R2 read length). An em-dash means no verified measurement exists and the value is omitted rather than approximated (testis clip rates; testis/cohort per-BAM read counts; and the cohort clip rate, whose in-run 0.015% warning was a head-of-chr1 sampling artefact and is never repeated as fact). **(b)** Clip rates where a verified value exists. The genome-wide qualifying rate on PBMC 10k v3 is 0.5730% (3,195,067 / 557,564,408 accepted cell-barcoded reads), the corrected constant, superseding the 1.152% docstring figure. Hatched bars are the v2 caller's head-sample QC estimator (first 200,000 cell-barcoded reads of a coordinate-sorted BAM; tool issue #99 §2, whose default has since changed on `develop` to an exact in-pass count, `--clip-rate-sampling pass`, merged in PR #100, with `head` retained as the v2 behaviour), which reads 2.2565% on PBMC where its own criteria measure 0.5364% genome-wide (~4.2× head bias): estimator values are comparable only with each other, never with the genome-wide bar. pbmc4k's estimator value is 1.64× donor 1's: the evidence channel is richer on donor 2. Cohort scope: 17 GSM libraries = 14 patients; the pre-registered primary excludes MetBone (15 GSMs = 12 patients); cells shown are the Stage-3 curated set (29,063) and its label-confirmed subset (18,651; 64.2%), not a CellRanger estimate.

## Fig S2 | v2 peak-call QC and the tier-2 cleavage-offset census

**(a)** Tier composition of every final v2 arm, with every count naming its arm: PBMC IP arm 333,920 calls (tier 1 167,565 / tier 2 166,355 scored), default 46,524 (P@100 0.7062); mice defaults 26,255 / 26,526 (0.7450 / 0.7572); single-molecule share of tier 1 is 72.2% on the PBMC IP arm and 72.1% on the no-IP arm (the value the text quotes). The no-IP ≥2-molecule file is post hoc and is not the default. **(b)** Tier-2 calls are wide intervals (medians 371 / 259 / 248 bp); tier-1 calls are 1-bp clip-anchored points. **(c)** Default calls per gene. **(d)** Distinct-clip-molecule distributions; selecting BED score ≥2 reproduces the default exactly (asserted per arm). **(e–g)** The ~90–105 nt tier-2 coverage offset (10x R2 coverage runs out before the poly(A) junction), measured on the development slices: four independent estimates agree (tool auto-offset 103 PBMC / 87 mouse; post-hoc argmax +95 on atlas P@10 and on Kinnex t5 P@10, where t5 = ≥5 long-read records at the terminus, not de-duplicated UMIs); the signed-distance mode moves to ~0 when corrected, and the tier-1 control sits at +0, so the offset is real and tier-2-specific. **Boxed negative disposition:** correcting it triples tier-2 P@10 but fails every pre-registered acceptance criterion (atlas-agreement P@100 remains ~0.085 vs null 0.028 on PBMC, no recall gain, internal-priming decoy rate more than triples); nothing is adopted: the disposition is to report inferred cleavage, not to move calls. Caveats: the census ran on development slices (the PBMC slice is clip-richer than the genome), so whether the offset holds for all 166,355 full-BAM tier-2 sites is an inference, not a measurement; the underlying sweep is provisional pending its own verifier.

## Fig S3 | Why the benchmark is built this way: regimes, chance and one reconciled null

**(a)** Against the 18,432,135-entry PolyASite dump with whole-peak-interval matching, five peak-calling strategies scored 0.996–1.000 (spread <0.004) while width-matched shuffled peaks already scored 0.62–0.75, and the two retired figures computed different nulls for the same arm (0.615 vs 0.753); under that regime the benchmark can rank nothing. Scored at the strand-matched 3′-most base against the curated PolyASite 2.0 representative sites, the same five arms separate (P@100 0.355–0.492) over one reconciled null (0.020–0.024). **(b)** Reference density recomputed on the curated point reference: 2.26% of gene-body bp lies within 100 bp of a same-strand curated site, and the measured null mean (0.0219) equals that local density within 3%: chance in this benchmark *is* reference density, which is why the null is indispensable. **(c)** The same `score_tool.py` null accompanies every verified score TSV: the pre-registered default scores 0.7062 / 0.7450 / 0.7572 against nulls of 0.0217 / 0.0139 / 0.0138 (33–55× chance), and every competitor is scored with its own identically built null. Caveats: panel a's left group is the retired record, shown solely as the discrepancy being reconciled, and none of its values may be quoted as benchmark results; the null≈density ratio (0.97 at 100 bp) is a consistency observation of this recompute, not an independently verified claim; the density denominator is the merged gene-body space the null shuffle actually uses (1.80 Gb), not the whole genome; scUTRquant is catalog-based and unranked; SCAPTURE mouse 2 is not plotted (site-level run scored 0.672; only mouse 1 carries a verified null-bearing row).

## Fig S4 | Second-donor validation: the unchanged default on pbmc4k (pre-registered)

Pre-registered before any pbmc4k number existed (driver frozen 19 minutes before the caller started); run on the identical frozen code, scorer, atlas and nulls; 107 of 108 recorded parameters identical, the one change being `--seq-len` 91→98, a library descriptor. **(a)** Gate P@100 ≥ 0.50: PASS at 0.8279 (38× its null), so the gate now holds on four libraries; the ≥1-molecule arm again has the higher F1_det (0.2635 vs 0.1948), so ≥2 molecules remains a reliability choice, not the F1 optimum. **(b)** Cross-donor concordance per the pre-registered protocol, both directions, never one alone: 84.2% of donor-2 default calls have a strand-matched donor-1 call within 100 bp (81.3% at 25 bp; ~361× the genic-shuffle null); the reverse direction is 39.9% against its 44.4% arithmetic ceiling (donor 1 emits 46,524 calls to donor 2's 20,672, i.e. call-count arithmetic, not disagreement). **(c)** The matched-call-count control, drawn so it cannot be buried: donor 1's default cut to donor 2's call count by any route scores P@100 0.886–0.907 with R_det 0.112–0.124, dominating donor 2 on both axes, so donor 2's higher headline atlas-agreement precision is an operating-point effect. **Precision generalises; it does not improve.** Caveats that travel: a second library, chemistry and CellRanger version, only presumptively a second individual (10x publishes no donor identifier); recall is genuinely lower on donor 2 (R_det 0.1104 vs 0.1754; survives every denominator swap, and the clip channel was 1.64× richer on donor 2, so channel poverty is no excuse); no claim about v2-vs-v3 chemistry as such.

## Fig S7 | The pre-registered trusted-novel definition and its failure (negative result)

Input: the final PBMC 10k v3 precision default (46,524 sites on primary contigs). The definition, committed before any number existed, was clip-supported ∧ ≥2 molecules ∧ not internal priming ∧ canonical hexamer at −40..−5 ∧ ≥100 bp from any PolyASite 2.0 site (PolyA_DB, hg19-only, could not be used); it yields 7,259 trusted-novel sites (15.6%). Truth: Kinnex x3p poly(A)-verified 3′ ends (different donors), hit = within 25 bp, same strand, at ≥5 supporting long-read records at the terminus (not de-duplicated UMIs). **(a)** The funnel with per-stage concordance: input 0.765 → hexamer 0.811 → atlas-novel 0.485 → strong hexamer 0.502; the atlas-novelty stage is what moves concordance; dashed line = the 0.70 target. **(b)** Concordance vs truth stringency, with the atlas-known hexamer-pass complement (0.894 at ≥5 records) calibrating the ceiling and the 10-seed shuffled null (0.007) as a band. **(c)** Feature classes (trusted-novel 69.4% intronic) and Kinnex internal-priming-decoy proximity (27.0% vs 7.6% for the atlas-known hexamer-pass complement). **(d, boxed, post hoc)** Concordance by feature class and molecule support, exploratory only; never call a de novo site "trusted" on its strength. Caveats that travel: this is a negative result and is written as one, 0.485 vs the ≥0.70 target, missed under every truth choice at the pre-registered 25 bp window (GEM-X 0.515, pooled 0.582; the 50/100 bp pooled values are not the pre-registered window); donor mismatch cannot explain the gap (the atlas-known complement scores 0.894 on the same truth), though truth is site-level and donor-mismatched, which caps the attainable fraction; enrichment over the null (65–179×, empirical p at the 1/11 floor) does not rescue an absolute-fraction target; the hexamer adds +0.046 overall but nothing among atlas-novel sites (hexamer-fail 0.487), because the novelty criterion selects the sites the long reads see least; the residual class survives both internal-priming rules (added on top of the shipped filter, a Kinnex-style A-richness rule removes 31 of 46,524 default sites, a no-op), so the internal-priming diagnosis, chosen after seeing the data, remains a hypothesis (decoy-proximal sites are less concordant, 0.39 vs 0.52: a plausible mechanism, not a proven one); the v1→v2 change (0.521 → 0.485) is descriptive, not a test; single PBMC donor, single BAM.

## Fig S8 | Compute detail behind Fig 3d

**(a, b)** Every PBMC 10k v3 arm from the verified compute registry. Rule in force: never quote wall time without the concurrency disclosure. The v2 arm wall times (34:37 no-IP, 32:59 IP) were measured with all four benchmark arms running concurrently, and the uncontended single run is 27:43. ## Fig S9 | Calibration deep-dive behind Fig 4

Same harness as Fig 4 (testis mouse 1; 20 shared label permutations; no permutation re-run, all panels reading the verified TSVs except the declared recomputation in b). **(a)** Per-stage-pair null p < 0.05 for all six configurations: no pair drives any verdict; the shipping configuration B0 (Fisher, cells, no marker pre-selection) spans 2.94–3.13% with 0/20 null runs carrying any q < 0.05 hit. **(b)** B0 stratified by a label-independent expression measure: every stratum is below the 5% nominal rate, never anti-conservative at any expression level (recomputed 2.5–4.0% under a declared binning; the verified range is 2.6–4.0% and the original bin edges were not persisted, a stated caveat; the pooled rate reproduces the verified 3.03% exactly). **(c)** Reads-mode pseudoreplication: 20.3% vs 13.0% null p < 0.05 with pre-selection on, 9.6% vs 3.0% with it off, and ~1,500 false q < 0.05 hits per null run in reads mode even without pre-selection. **(d)** Permutation-calibrated q vs nominal BH q on the true runs; for B0 the permutation null is conservative and calibrated q adds hits (60,332 → 66,630; 46,230 after the effect floor). True hit counts are not comparable across marker modes (different tested universe and a different Fisher gene denominator). **(e)** The negative-binomial plug-in dispersion floor (10⁻⁴): in the pre-selection-off arm, 8.5% of null tests carry 67% of null q < 0.05 hits (13% in the marker arm). Rule that ships: whenever marker pre-selection or `nb_pairwise` is used, permutation-calibrated q is required. Caveats: single mouse, single tissue, very large true stage effects; the label-permutation null tests exchangeability under the global null only; KS rejects for every arm (discrete Fisher) and is reported, not gated; "calibrated" is the pre-registered operational rule, not a standard.

## Fig S10 | The dropped clustering claim, stated honestly

**(a)** PBMC 10k v3: clustering on all 275,370 PAS-site counts recovers GEX marker cell types (AMI 0.708, ARI 0.502), but summing the same counts to 14,891 per-gene totals, discarding all site-level resolution, recovers them just as well (AMI 0.6978; k-matched 0.7878 vs 0.7602). Site resolution adds nothing, so the recovery is 3′-end expression signal re-encoded, not isoform choice; the positive result never appears without this ablation on the same axis. **(b)** The (dropped) positive result replicates: 17/17 Laughney libraries, median AMI 0.662 (range 0.367–0.779). **(c)** The retired parameter sweep's one durable finding: Leiden resolution dominates cluster count (+112.5% median, 17/17 datasets) while every annotation-trim knob is at least 8× smaller. Caveats that travel: the reference partition is marker-derived, not curated truth; per-site counts carry gene abundance, and panel a shows abundance suffices, so no isoform-choice signal is demonstrated; concordance is scored on GEX-labelled cells only (median coverage 0.498; coverage does not drive agreement, ρ −0.34, p 0.18); no stage effect is claimed; the isoform-only usage-fraction spaces are excluded (mis-keyed matrices, re-run pending; the ablation verdict does not depend on them); `--min-pas-prominence` is proven byte-identically inert on the lambda strategies, so no prominence arm of the retired sweep could have been informative; the library-size bar's median must not be quoted alone (per-dataset range −41.7% to +93.3%); cluster count is a granularity proxy, and nothing here says cell assignments are stable across knobs.
