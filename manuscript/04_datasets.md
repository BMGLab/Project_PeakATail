# PeakATail Manuscript — Dataset Shortlist (verified 2026-08-12)

All accessions below were checked this session via web search / direct fetch of GEO, EGA, ArrayExpress, PacBio, and the primary papers. Items marked **FLAG** have a chemistry or access problem that affects PeakATail (which requires CB/UB-tagged BAMs from 10x 3' libraries, i.e. raw FASTQ or BAM access — cellxgene h5ad is not sufficient).

## Cross-cutting flags

1. **Chemistry:** Every 10x 5' library (MAS-ISO-seq TILs, the 5' halves of GSE163120 and PacBio's 5' Kinnex sets) is unusable for 3'-end PAS calling — filter sample lists explicitly. 10x v1/GemCode (68k PBMC) support should be tested before promising it.
2. **Access timeline:** EGA controlled-access items (EGAS00001004871 GBM, EGAS00001005173 breast, EGAS00001005597 CLL, EGAS00001006807 HGSOC) need DAC applications now if they are to make the manuscript; none is on the critical path — each has an open substitute.
3. **h5ad-only trap:** LuCA atlas and GSE154763 cannot feed PeakATail directly; use atlases for annotations/label transfer only, and run `ema` on component-study FASTQs (Lambrechts E-MTAB-6149/6653 verified open).
4. **Suggested minimal core:** GSE130708 + FLAMES scmixology + Kinnex PBMC (truth); pbmc_10k_v3 + pbmc8k + GSE104556 (benchmark vs scAPA/Sierra/SCAPTURE on their own inputs); GSE123904 + LuCA subset + GSE163120-mouse (or GSE156625) (application); GSE126030 + GSE96583 (known APA biology). All of these are open-access.
